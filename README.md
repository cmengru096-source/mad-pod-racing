# Mad Pod Racing · 碰撞预测与滚动搜索

高速过弯时，朝下一个检查点全速前进可能会让赛车在出弯时朝错方向。这个项目用两个可重复运行的实验研究竞速决策。一个预测两辆赛车在本回合何时相撞，另一个比较不同动作序列能提前多少回合到达终点。

## 运行实验

使用 Python 3.10 或更新版本，在仓库根目录运行。只依赖 Python 标准库。

```sh
python search_demo.py
python -m unittest discover -s tests -v
```

双方实验使用相同初始位置、速度和检查点顺序，搜索使用随机种子 41。表中数字是完成场景所需的回合数，越少越好。

| 本地实验 | 全速瞄准下一检查点 | 滚动搜索 |
| --- | ---: | ---: |
| 正面相向，一处检查点 | 24 | 18 |
| 无对手，四处检查点一圈 | 74 | 55 |

在相向场景中，搜索在第 1 回合选择护盾，计入失去推力的代价后仍提前 6 回合到达。在四检查点实验中，第 12 回合时搜索策略的剩余路线反而更长，最终却早 19 回合完赛。只比较某一帧到检查点的距离，会漏掉出弯方向的价值。

## 物理模型

两车的碰撞半径各为 400。若圆心相距 1,100、以每回合 600 的相对速度直线接近，首次接触就在本回合的第 0.5 处。一般情形下，模型求满足两车圆心距离等于 800 的最早时刻，推进到接触点，按接触法线、质量和最小冲量更新速度，再检查本回合剩余时间内的碰撞。

检查点沿整段运动路径检测，高速经过也能计入。回合结束时处理摩擦和取整。四车实验中，同队两车共用一次 BOOST，护盾通过改变质量影响碰撞。[物理实现](physics.py) · [碰撞、护盾和共享加速测试](tests/test_physics.py)

## 搜索策略

演示程序向前模拟 12 回合，只执行第一步。到下一回合，它把上一条最优计划前移一位作为初始候选，保留 5 个高分计划，用单点交叉和连续 1 至 3 步的变异生成新动作。每次决策固定评估 80 条计划。候选优先比较能否完赛和完赛回合，再考虑剩余路线与朝向检查点的速度。[实现](search_demo.py) · [固定种子与完赛结果测试](tests/test_search_demo.py)
